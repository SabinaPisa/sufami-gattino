# SUFAMI 🐈‍⬛✨ — *Gattino Nero dagli Occhi di Giada*

Benvenuti nel piccolo universo digitale dedicato a **Sufami**, un felino di tre anni dal manto corvino e dallo sguardo ipnotico color verde smeraldo.

Questo progetto nasce come omaggio affettuoso alla sua presenza discreta, elegante ed enigmatica — un'esistenza che si muove con grazia felina tra ombra e luce.

### ✨ Il Progetto
Un sito web minimalista e interattivo che celebra la quotidianità di Sufami attraverso una galleria fotografica intima e un piccolo gioco interattivo.

- **Galleria:** istantanee autentiche che catturano la sua indole: curiosa, sonnolenta, a tratti impertinente.
- **Interazione:** un'esperienza ludica leggera, pensata per evocare il suo spirito sfuggente.
- **Estetica:** design essenziale, notturno, con accenti luminosi — proprio come i suoi occhi nel buio.

### 🖤 Filosofia
> Sufami non è semplicemente un gatto. È un'attitudine. Una forma di quiete vigile, di eleganza non ostentata. Questo sito cerca di tradurre in codice quella medesima quiete.

Realizzato con affetto, HTML, CSS e JavaScript. Nessun framework, solo l'essenziale.
